## ⚠️ 本仓库 push 经验（环境关键）
- bash 沙箱内 `git push` 静默失败：空输出 exit 1，git 无法弹凭据输入（/dev/tty 不可用），`GIT_TERMINAL_PROMPT=0` 后报 "could not read Username"。
- 已配仓库级凭据助手：`git config --local credential.https://github.com.helper "!gh auth git-credential"`（gh CLI 已登录，token 可读）。
- **用 PowerShell 工具执行 `git push origin main` 可成功**（bash 沙箱会吞输出）；push 后务必 `git status -sb` / `git ls-remote` 验证远端同步。
