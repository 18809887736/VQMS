🧮 VQMS 核心算法（端到端速览）

一屏看全「原始曲线 → 日/月/年合格率」。细节/边界防御/为什么见 项目规划_v3_2.md §5.5–§5.7。

判定公式（AVC 口径，§2.2 / §5.3）

dev = average_SV − plan_SV；|dev| ≤ tolerance_v → 合格（含边界）；dev > +tol → 偏高（over_high）；dev < −tol → 偏低（over_low）。容差随阈值行生效：220kV=±300V、500kV=±500V。

端到端流水线（每日 stat_date 次日调度，按组 group_num 推进；游标 precompute_cursor 按组、与组内日表 UPSERT 同事务）

① 取数（两路独立，边界放宽 ±1 天，§5.7.3 ①-a 三步闸门：正则→解析→真实时间过滤）
   电压路 his_curve_sv(该组全部 busbar_num)  ;  yx 路 yc_history(指示点 + 门控点)
② 时间对齐到分钟（§5.5）
   电压桶 (t × busbar_num)：多条→avg 均值、plan 末条；缺→标记
   yx 桶 (t)：取 ≤ t 最近一条（阶跃保持）
③ 逐对齐分钟 t：
   层 0 §5.1.1 判主母线 mainBusbarNum(t)（整组一次；失效→组级空档，不计任何母线）
   仅对 busbar_num = mainBusbarNum(t) 跑三关（§5.7.2）：
     层 1 门控关  → 命中剔除(excluded)
     层 2 数据关  → plan 废值按 plan_sv_invalid_policy：SKIP 剔除 / COUNT 不合格 / FALLBACK 回退
     层 3 合格关  → 合格 / 偏高 / 偏低
④ 组内每条 busbar_num UPSERT voltage_quality_daily
⑤ 月/年（§5.7.4）：daily→monthly→yearly，纯加权 SUM，沿用 v3.1 §6.3

四层判定速查（§5.7.3，层 0 先于三关）

层判什么不通过归宿
0 主母线归属
（§5.1.1，组级）		该分钟主母线是哪条是副母线→跳过（不在窗口，不计 total/excluded）；失效→组级空档
1 门控关（§5.4）装置退出？（远方就地=0 / AVC 退）命中→剔除（excluded）
2 数据关（§5.3）plan_SV 废/缺值？SKIP→剔除(excluded)；COUNT→不合格；FALLBACK→回退判
3 合格关（§5.3 AVC）|avg−plan| 超容差？合格 / 偏高 / 偏低

合格率与对账（§5.6 / §5.7.1）

  • 日：qualification_rate = qualified / total × 100，total = qualified + over_high + over_low
  • total + excluded = 该母线当天充当主母线的全部分钟（excluded 只含层 1/2 剔除，不含层 0 跳过与组级空档）
  • 月/年：rate = SUM(qualified) / SUM(total) × 100（绝不直接 AVG rate 列）；avg_SV 按 total 加权；excluded = SUM(excluded)
