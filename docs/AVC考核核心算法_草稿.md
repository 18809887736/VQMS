# 一、AVC 投运率算法

> 依据附件6 §一。投运率考核 **AVC 装置在不在线**（时间记账），与调节合格率是两个独立维度；投运率不适用 §三 免考（免考仅作用于调节合格率），它有自己的免责——"扣除电网原因退出时间"。

## 1.1 公式

```
AVC 投运率 = AVC 投运时间 / 并网运行时间 × 100%
合格标准：≥ 99%
考核单价：每缺 1 个百分点 = 额定容量 × 0.02 分/万千瓦
```

- **并网运行时间** = 统计周期（月）内并网主体并网运行的总分钟数。
- **AVC 投运时间** = 并网运行时间 − AVC 退出时间。

## 1.2 投退信号来源

**`yc_history` 表**（AVC 投退 yx 点）：

| 字段 | 含义 |
|---|---|
| `yc_num` | 遥测点编码（现场人员整定） |
| `yc_time` | 时间戳 |
| `yc_data` | `1` = AVC 投；`0` = AVC 退 |

- `yc_time` 就近取整到分钟（秒 ≥ 30 进位），与 `his_curve_sv` 共用时间原则。
- yx 为阶跃保持量：`yc_data` 在两次变位之间**保持上一值**（取最近一条 ≤ 当分钟）。

## 1.3 逐分钟投运状态判定

对统计周期内每一分钟 `t`：

```
并网(t)   = 该分钟并网主体是否并网运行（来源待定：机组并网信号 / 合并）
avc_in(t) = 主 AVC 投退点在 t 时刻的保持值（1=投 / 0=退）

if 并网(t):
    if avc_in(t) == 1:  → 投运分钟 +1
    else:               → 退出分钟 +1（进一步分：电网原因 / 非电网原因）
# 未并网(t) 不计入任何分钟
```

## 1.4 免责：扣除电网原因退出时间

投运率免责是**时间扣减**（与调节合格率的免考无关）：

```
AVC 投运时间 = 并网运行时间 − Σ退出分钟
退出分钟    = 非电网原因退出分钟 + 电网原因退出分钟
免责       = 扣除 "电网原因退出分钟"（不计入分母的惩罚基数）

即：惩罚性退出 = 非电网原因退出分钟；电网原因退出不罚
```

> **退出原因来源待定**：`warn_info` / `yc_history` 是否有"AVC 退出原因"点位？若无，电网原因 vs 非电网原因的区分留人工标注或上游系统。

## 1.5 统计

```
投运率 = 投运分钟 / (投运分钟 + 非电网原因退出分钟) × 100%
        （电网原因退出分钟从分母扣除）
缺额   = max(0, 99% − 投运率)
考核量 = 缺额百分点 × 额定容量 × 0.02 分/万千瓦
```

# 二、调节合格率算法

---

## 2.1 判定对象与目标

**对象**：一条 AVC 指令（发令事件）= `warn_info` 表里一条指令记录（`warn_type=5`，含目标值或增量值）。

**目标电压 `V_target`（kV）**——指令解码后的绝对目标电压：
- **目标值形态**：文本数值 ÷ 100 → kV（如 `22315` → **223.15 kV**）
- **增量值形态**：解码 4 位编码 → 增量幅值 × 100V × 方向，再 **+ 当前实时母线电压** → 绝对目标（如 `2202` = +200V；当前 234.25 kV + 0.2 → **234.45 kV**）

> 指令只考虑电压指令；无功指令留接口。**不从 `his_curve_sv.plan_SV` 取目标**——目标来自 `warn_info`。

---

## 2.2 数据对齐（按分钟）

每分钟一条 `his_curve_sv` 记录，携带该分钟的 `high_SV` / `low_SV`（kV，**判定用字段**）。

- **时间原则**：原始 `save_time` 就近取整到分钟（秒 ≥ 30 进位）。
- **按主母线分组**：`busbar_num`（来自 `yc_history` 主母线号点）筛选本指令作用的主母线。
- **基准时刻 `t₀`** = 指令下达时刻（`warn_info.warn_time` 就近取整到分钟）。
- **第 k 分钟组**（k=1,2,…）：`[t₀ + (k−1)min, t₀ + k·min)` 区间的记录。

---

## 2.3 区间聚合（包络并集）

N 分钟窗口内每分钟一组 `(high_SV_k, low_SV_k)`，聚合为**一组综合区间**：

```
综合区间 [L_N, H_N] = [ min(low_SV_1..N),  max(high_SV_1..N) ]
```

- `L_N` = 窗口内所有分钟 `low_SV` 的最小值（下包络）
- `H_N` = 窗口内所有分钟 `high_SV` 的最大值（上包络）
- 语义：窗口内电压摆动**曾覆盖到的最宽范围**。

---

## 4. 分档判定（核心）

### 2.4.1 整定参数

| 参数 | 含义 | 默认 |
|---|---|---|
| `T_fast` | 快速性档窗口上界 | 5 min |
| `T_econ` | 经济性档窗口上界 | 待定（"≥5"取一个上限，如 30 min） |

> "1 分钟"原始合格线**不再单列**（已废）；`T_fast`、`T_econ` 现场可整定。

### 2.4.2 两档窗口

| 档 | 扫描窗口 | 综合区间 |
|---|---|---|
| **快速性档** | 第 1 ~ T_fast 分钟 | `[L_fast, H_fast]` |
| **经济性档** | 第 T_fast+1 ~ T_econ 分钟 | `[L_econ, H_econ]` |

### 2.4.3 判定逻辑（按时间先后，先到先归类）

```
若 V_target ∈ [L_fast, H_fast]   → 快速性合格点（调得快：短窗内就够到目标）
否则 若 V_target ∈ [L_econ, H_econ] → 经济性合格点（调得慢：短窗没够到、长窗才够到）
否则                                 → 不合格（整个 [0, T_econ] 都没覆盖目标）
```

**图示**：
```
指令 t₀
 │
 ├──── 快速性窗 [1, T_fast] ────┼──── 经济性窗 [T_fast+1, T_econ] ────┤
 │   综合区间 [L_fast,H_fast]   │   综合区间 [L_econ,H_econ]          │
 │                               │                                      │
 │  V_target ∈ 此区间?           │  V_target ∈ 此区间?                 │
 │   是 → 快速性合格点(停)       │   是 → 经济性合格点(停)             │
 │   否 → 进入经济性窗           │   否 → 不合格                       │
```

---

## 2.5 状态机（含免考）

每个指令点判定输出**五态**之一（三状态模型的扩展）：

| 状态 | 条件 | 计合格？ | 扣罚 |
|---|---|---|---|
| **快速性合格** | `V_target ∈ [L_fast, H_fast]` | ✅ | 不罚 |
| **经济性合格** | 短窗未夹住、`V_target ∈ [L_econ, H_econ]` | ✅ | 不罚 |
| **不合格（非免考）** | 两窗都没夹住、不满足免考条件 | ❌ | ✅ 罚 |
| **不合格（免考）** | 两窗都没夹住、但全部 AVC 无功设备已正确方向顶满仍不达标 | ❌ | ❌ 不罚（剔除法：不计率、不计罚） |

> 免考判定见 [免考条款适用范围.md](政策口径/免考条款适用范围.md)「最大无功功率发出或吸收能力」概念；需设备级无功遥测，VQMS 若拿不到则免考留人工。

## 2.6 伪代码

```python
def judge_command(cmd, curve_by_minute, main_busbar, thresholds, t0):
    V_target = decode_target(cmd)                 # 目标值÷100 或 增量解码+当前电压
    T_fast, T_econ = thresholds.t_fast, thresholds.t_econ

    # 快速性窗
    rows_fast = curve_by_minute(main_busbar, t0, from_min=1, to_min=T_fast)
    L_fast, H_fast = min(r.low_SV for r in rows_fast), max(r.high_SV for r in rows_fast)

    if L_fast <= V_target <= H_fast:
        return STATE.QUICK_QUALIFIED              # 快速性合格点

    # 经济性窗
    rows_econ = curve_by_minute(main_busbar, t0, from_min=T_fast+1, to_min=T_econ)
    L_econ, H_econ = min(r.low_SV for r in rows_econ), max(r.high_SV for r in rows_econ)

    if L_econ <= V_target <= H_econ:
        return STATE.ECON_QUALIFIED               # 经济性合格点

    # 两窗都没夹住 → 不合格；再判免考
    if is_exempt(cmd, t0, main_busbar):          # 全部无功设备正确方向顶满?
        return STATE.UNQUALIFIED_EXEMPT          # 不计率、不计罚
    return STATE.UNQUALIFIED_PENALIZED           # 罚
```

## 2.7 调节合格率统计（剔除法）

```
快速性合格率 = 快速性合格点数 / 发令有效次数 × 100%
经济性合格率 = 经济性合格点数 / 发令有效次数 × 100%
调节合格率   = (快速性合格 + 经济性合格) / 发令有效次数 × 100%

发令有效次数 = 发令总次数 − 免考点数          # 免考点剔除（不计分母）
扣罚量 ∝ 不合格-非免考点数
```

## 2.8 边界情况 / 待定

| 项 | 处理 |
|---|---|
| 窗口内某分钟**缺数据**（无 his_curve_sv 记录） | 该分钟是否计入综合？草稿暂定：缺数据分钟跳过（不计入 min/max），但记日志；若整窗全缺 → 该指令判定失效、剔除 |
| `T_econ` 上限 | "≥5min"无上界会导致长越限永远在经济性窗内算合格？**需定上限**（如 30 min），超出即不合格 |
| 目标值/增量**解码失败**（编码异常） | 跳过 + 记日志，不计入发令次数 |
| 多条指令**时间重叠** | 按 `obj_num`/主母线分通道，各判各的 |
| **缺当前实时电压**（增量形态算目标用） | 取 t₀ 时刻最近一条实时电压；缺失则该指令跳过 |
| 综合区间 `L > H`（数据异常，low>high） | 视为该窗无效，记日志 |

> 本文件为草稿。`T_econ` 上限、缺数据策略、目标解码的具体位定义（增量第2位"循环码"含义）等，待真实数据验证后定稿。
