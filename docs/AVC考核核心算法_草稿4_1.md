# 一、AVC 投运率算法

> 依据附件6 §一。投运率考核 **AVC 装置在不在线**（时间记账），与调节合格率是两个独立维度；投运率不适用 §三 免考（免考仅作用于调节合格率），它有自己的免责——"扣除电网原因退出时间"。

## 1.1 公式

```
AVC 投运率 = AVC 投运时间 / 并网运行时间 × 100%
合格标准：≥ 99%
考核单价：每缺 1 个百分点 = 额定容量 × 0.02 分/万千瓦
```

- **并网运行时间** = 统计周期（月）内并网主体并网运行的总分钟数。
- **AVC 投运时间** = 并网运行时间 − AVC 退出时间。

## 1.2 投退信号来源

**`yc_history` 表**（AVC 投退 yx 点）：

| 字段 | 含义 |
|---|---|
| `yc_num` | 遥测点编码（现场人员整定） |
| `yc_time` | 时间戳 |
| `yc_data` | `1` = AVC 投；`0` = AVC 退 |

- `yc_time` 就近取整到分钟（秒 ≥ 30 进位），与 `his_curve_sv` 共用时间原则。
- yx 为阶跃保持量：`yc_data` 在两次变位之间**保持上一值**（取最近一条 ≤ 当分钟）。
- 合成库投退点号 = **yc3009**（`tools/avc-data-gen/config/points.yaml`；真实现场待核对）。

## 1.3 逐分钟投运状态判定

对统计周期内每一分钟 `t`：

```
并网(t)   = 该分钟并网主体是否并网运行
           （信号点：yc511 正母 / yc512 副母，值 = 带电×10 + 机组数、≥10 即并网——
             合成库已定义，真实现场待核对，见 v4.1 §8.3；原「来源待定」作废）
avc_in(t) = 主 AVC 投退点在 t 时刻的保持值（1=投 / 0=退）

if 并网(t):
    if avc_in(t) == 1:  → 投运分钟 +1
    else:               → 退出分钟 +1（进一步分：电网原因 / 非电网原因）
# 未并网(t) 不计入任何分钟
```

## 1.4 免责：扣除电网原因退出时间

投运率免责是**时间扣减**（与调节合格率的免考无关）：

```
AVC 投运时间 = 并网运行时间 − Σ退出分钟
退出分钟    = 非电网原因退出分钟 + 电网原因退出分钟
免责       = 扣除 "电网原因退出分钟"（不计入分母的惩罚基数）

即：惩罚性退出 = 非电网原因退出分钟；电网原因退出不罚
```

> **退出原因点位（2026-08-17 补，取代原「来源待定」）**：**yc521（正母）/ yc522（副母）**——0=未退 / 1=电网原因（免责）/ 2=非电网（扣罚）。合成库已定义（`tools/avc-data-gen/config/points.yaml`，映射自 `docs/外部DB/JS计算引擎说明.md`）；真实现场待对端 JS 引擎部署与点号核对（v4.1 §14-8）。

## 1.5 统计

```
投运率 = 投运分钟 / (投运分钟 + 非电网原因退出分钟) × 100%
        （电网原因退出分钟从分母扣除）
缺额   = max(0, 99% − 投运率)
考核量 = 缺额百分点 × 额定容量 × 0.02 分/万千瓦
```

# 二、调节合格率算法

---

## 2.1 判定对象与目标

**对象**：一条 AVC 指令（发令事件）= `warn_info` 表里一条指令记录（`warn_type=5`，含目标值或增量值）。

**目标电压 `V_target`（kV）**——指令解码后的绝对目标电压：
- **目标值形态**：文本数值 ÷ 100 → kV（如 `22315` → **223.15 kV**）
- **增量值形态**：解码 4 位编码 → 增量幅值 × 100V × 方向，再 **+ 当前实时母线电压** → 绝对目标（如 `2202` = +200V；当前 234.25 kV + 0.2 → **234.45 kV**）

> 指令只考虑电压指令；无功指令留接口。**不从 `his_curve_sv.plan_SV` 取目标**——目标来自 `warn_info`。

---

## 2.2 数据对齐（按分钟）

每分钟一条 `his_curve_sv` 记录，携带该分钟的 `high_SV` / `low_SV`（kV，**判定用字段**）。

- **时间原则**：原始 `save_time` 就近取整到分钟（秒 ≥ 30 进位）。
- **按主母线分组**：`busbar_num`（来自 `yc_history` 主母线号点）筛选本指令作用的主母线。
- **基准时刻 `t₀`** = 指令下达时刻（`warn_info.warn_time` 就近取整到分钟）。
- **第 k 分钟组**（k=1,2,…）：`[t₀ + (k−1)min, t₀ + k·min)` 区间的记录。

---

## 2.3 区间聚合（包络并集）

N 分钟窗口内每分钟一组 `(high_SV_k, low_SV_k)`，聚合为**一组综合区间**：

```
综合区间 [L_N, H_N] = [ min(low_SV_1..N),  max(high_SV_1..N) ]
```

- `L_N` = 窗口内所有分钟 `low_SV` 的最小值（下包络）
- `H_N` = 窗口内所有分钟 `high_SV` 的最大值（上包络）
- 语义：窗口内电压摆动**曾覆盖到的最宽范围**。

---

## 2.4 分档判定（核心）

### 2.4.1 整定参数

| 参数 | 含义 | 取值 |
|---|---|---|
| `T_fast` | 快速性档窗口上界 | **∈ [1,5) 整数可整定，默认 4**（Leo 2026-08-14 拍板；原"5 min"作废） |
| `T_econ` | 经济性档窗口上界 | **= 5，写死**（Leo 2026-08-14 拍板；原"待定上限"作废——指令实际 5 分钟间隔 → 判定窗口 = 5 分钟、两档不重叠） |

> "1 分钟"原始合格线**不再单列**（已废）；`T_fast` 现场可整定（存 `vqms_judge_param`，v4.1 §6.2.5），`T_econ` 写死 5 不再可整定。

### 2.4.2 两档窗口

| 档 | 扫描窗口 | 综合区间 |
|---|---|---|
| **快速性档** | 第 1 ~ T_fast 分钟 | `[L_fast, H_fast]` |
| **经济性档** | 第 T_fast+1 ~ T_econ 分钟 | `[L_econ, H_econ]` |

> 两档窗口**无缝拼接**覆盖 `[1, T_econ] = [1, 5]`：`[1, T_fast] ∪ [T_fast+1, 5] = [1, 5]`——任何 `T_fast` 整定值下**无空档、无重叠**，不存在"调小 T_fast 后中间分钟脱离考核"的空隙（2026-08-19 显式化注：正文原只写"两档不重叠"，全覆盖性质此前需从本表推导，现钉死）。

### 2.4.3 判定逻辑（两档平行考察，互不隶属）

> **模型变更（2026-08-13）**：两档改为**平行考察**——快速性档和经济性档是两个**并列的独立考核项**（贴合附件6 把「调节快速性考核」「调节经济性考核」列为两个独立考核项），各自独立判、互不依赖，各出各的合格率、各算各的罚款。**旧模型是串联 fall-through（短窗没夹住才进长窗），已废弃。**

两档**并行**各判一次（不串行、不 fall-through）：

```
快速性档：V_target ∈ [L_fast, H_fast]？  → 快速性合格 / 快速性不合格
经济性档：V_target ∈ [L_econ, H_econ]？  → 经济性合格 / 经济性不合格
（两档判定彼此独立，互不影响）
```

- 一条指令可能「快速性合格 + 经济性不合格」「两档都合格」「两档都不合格」——四种组合都合法。
- **免考是档级触发**：某档不合格时，单独判该档是否免考（全部 AVC 无功设备正确方向顶满仍不达标 → 该档免考、剔除）。免考结论**不跨档**：快速性免考与否不决定经济性免考。（2026-08-13 起：免考**判定**是对端义务——VQMS 后置读 `yx501` 应用，见头部①；逐档应用的独立性不变。）

**图示**（两路并行，从 t₀ 出发分叉）：
```
指令 t₀、目标 V_target
 │
 ├─→【快速性窗 [1, T_fast]】综合区间 [L_fast, H_fast]
 │       V_target ∈ 此区间?
 │        ├ 是 → 快速性合格
 │        └ 否 → 快速性不合格（再单独判免考）
 │
 └─→【经济性窗 [T_fast+1, T_econ]】综合区间 [L_econ, H_econ]
         V_target ∈ 此区间?
          ├ 是 → 经济性合格
          └ 否 → 经济性不合格（再单独判免考）

（两条路径并行、各自收尾；互不隶属、不 fall-through）
```

## 2.5 状态机（两档平行，各自三态）

> ⚠️ **本节三态（含 `EXEMPT`）已被 2026-08-13 拍板取代**（头部①）：judge 只出两态、免考 = 后置读对端 `yx501`；本表与 §2.6 伪代码保留作算法推演存档，**工程实现以 v4.1 §8.2 三阶段管线为准**。
>
> **模型变更（2026-08-13）**：状态机随之改为**两档各自独立**——每档独立产出一个三态结果，一条指令最终有两个结论（快速性结论 + 经济性结论）。旧的单指令五态模型已废弃。

每档各判一次，各落 **三态**之一：

| 档态 | 条件 | 计该档合格？ | 该档扣罚 |
|---|---|---|---|
| **该档合格** | `V_target ∈ [L_档, H_档]` | ✅ | 不罚 |
| **该档不合格（非免考）** | 该档没夹住、不满足免考条件 | ❌ | ✅ 罚（计入该档罚款） |
| **该档不合格（免考）** | 该档没夹住、但全部 AVC 无功设备已正确方向顶满仍不达标 | ❌ | ❌ 不罚（剔除法：不计该档分母、不计罚） |

- 对快速性档：区间用 `[L_fast, H_fast]`，罚的是「调得慢」。
- 对经济性档：区间用 `[L_econ, H_econ]`，罚的是「持续越限的经济代价」。
- **两档独立判罚**：一条指令可能在快速性档被罚、经济性档合格（调得慢但最终调到了），反之亦然。
- **免考逐档判**：免考结论不跨档（见 §2.4.3）。（原「需设备级无功遥测、拿不到则免考留人工」——2026-08-13 起改为读对端 `yx501`，不再留人工。）

> 免考判定见 [免考条款适用范围.md](政策口径/免考条款适用范围.md)「最大无功功率发出或吸收能力」概念。

## 2.6 伪代码

> ⚠️ 下述伪代码为三态模型的历史版本，**保留作推演参考**；工程实现（两态 + 免考后置读 `yx501`）见头部①与 v4.1 §8.2。

```python
def judge_command(cmd, curve_by_minute, main_busbar, thresholds, t0):
    V_target = decode_target(cmd)                 # 目标值÷100 或 增量解码+当前电压
    T_fast, T_econ = thresholds.t_fast, thresholds.t_econ

    # 两档并行（互不依赖、不 fall-through）
    result = {}

    # 快速性档
    rows_fast = curve_by_minute(main_busbar, t0, from_min=1, to_min=T_fast)
    L_fast, H_fast = min(r.low_SV for r in rows_fast), max(r.high_SV for r in rows_fast)
    if L_fast <= V_target <= H_fast:
        result['fast'] = STATE.QUALIFIED
    elif is_exempt(cmd, t0, main_busbar):         # 免考逐档判：全部无功设备正确方向顶满?
        result['fast'] = STATE.EXEMPT             # 该档免考（剔除）
    else:
        result['fast'] = STATE.PENALIZED          # 该档罚

    # 经济性档（判定独立于快速性档结果）
    rows_econ = curve_by_minute(main_busbar, t0, from_min=T_fast+1, to_min=T_econ)
    L_econ, H_econ = min(r.low_SV for r in rows_econ), max(r.high_SV for r in rows_econ)
    if L_econ <= V_target <= H_econ:
        result['econ'] = STATE.QUALIFIED
    elif is_exempt(cmd, t0, main_busbar):         # 免考逐档判
        result['econ'] = STATE.EXEMPT
    else:
        result['econ'] = STATE.PENALIZED          # 该档罚

    return result                                  # {'fast': ..., 'econ': ...} 两个独立结论
```

## 2.7 调节合格率统计（两档各自剔除法）

> **模型变更（2026-08-13）**：统计随之改为两档各自独立。每档独立算一个合格率、一个罚款额；不再把两档合成单一合格率。

```
# —— 快速性档 ——
快速性发令有效次数 = 发令总次数 − 快速性免考点数     # 免考逐档剔除（不计该档分母）
快速性合格率 = 快速性合格点数 / 快速性发令有效次数 × 100%
快速性缺额   = max(0, 100% − 快速性合格率)
快速性罚款   = 快速性缺额百分点 × 额定容量 × 0.02 分/万千瓦

# —— 经济性档（分母、免考独立于快速性档）——
经济性发令有效次数 = 发令总次数 − 经济性免考点数
经济性合格率 = 经济性合格点数 / 经济性发令有效次数 × 100%
经济性缺额   = max(0, 100% − 经济性合格率)
经济性罚款   = 经济性缺额百分点 × 额定容量 × 0.02 分/万千瓦

# —— 总览（两个并列结果，不合并）——
调节合格率：分别报告「快速性合格率」和「经济性合格率」
调节罚款   = 快速性罚款 + 经济性罚款
```

- 两档分母独立：同一条指令可能在快速性档免考（不进快速性分母）、在经济性档非免考（进经济性分母），互不影响。（免考点识别 = 后置读 `yx501`，见头部①。）
- 「缺 1 个百分点 = 额定容量 × 0.02 分/万千瓦」的考核单价两档通用，分别按各自缺额计。
- 附件6 §二 原始口径（执行合格点数 / 发令次数）与 VQMS 细化的剔除法之间的口径选择仍待业务确认（见 §2.8）。
