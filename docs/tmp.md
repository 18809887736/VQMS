| 字段 | 含义 | 备注 |
|---|---|---|
| `warn_type` | 通常为 `5` | 现场人员整定 |
| `obj_num` | 对象编号 | 现场人员整定 |
| `warn_info` | 目标值 或 增量值 | 文本内含数值，见下 |

指令有两种形态（`warn_info` 文本示例）：

- **增量值**：`收到远方遥调执行指令:辽宁母线电压增量指令编码值处理,2202.`
  - 编码 `2202` 解码（左起 4 位）：
    - **第 1 位 `2`** —— 方向：`2` = 增加，`1` = 减少
    - **第 2 位 `2`** —— 循环码（具体含义待确认）
    - **第 3–4 位 `02`** —— 增量幅值，每单位 100V → `02` = **200V**
  - ⇒ `2202` = **电压增加 200V**
  - 💡 **增量值 + 当前实时母线电压 = 绝对目标值**（与"目标值"形态殊途同归）。例：当前电压 `234.25 kV` + `0.2 kV`（200V）= 目标 `234.45 kV`。两种指令形态最终都产出一个绝对目标电压。
- **目标值**：`收到远方遥调执行指令:主省220KV目标值,22315.` —— 代表 **223.15 kV**
- 其他类型：预留

> 一条指令由（`warn_type`、`obj_num`、目标值或增量值）表征。本项目给个初始值后，保留 **CRUD 的读取、更新**功能。

## 三个状态，不是两个

严格按 §二 定义，`执行合格点数` = "指令下达后 **1 分钟内**调到合格区间"的发令点数。你说的这个点 **>1 分钟才到位（或没到位）**，本身就不满足"1 分钟内"这条——所以它**不是执行合格点**，这一点不因免考而改变。

免考不是"把不合格翻成合格"，而是"不罚"。所以一个发令点其实有**三种状态**：

| 状态                     | 条件                                          | 计入 `执行合格点数`？ | 是否扣罚   |
| :----------------------- | :-------------------------------------------- | :-------------------- | :--------- |
| **执行合格**             | 1 分钟内调到合格区间                          | ✅ 是                  | 不罚       |
| **执行不合格（非免考）** | >1 分钟、且不满足免考条件                     | ❌ 否                  | ✅ 罚       |
| **执行不合格（免考）**   | >1 分钟、但全部无功设备已正确方向顶满仍不达标 | ❌ **否**              | ❌ **不罚** |





你问的就是第三行：**不算执行合格点数，但也不扣罚**。

## 那调节合格率公式怎么算它？

`调节合格率 = 执行合格点数 / 发令次数`。免考点既不算合格、又不该罚——那它进不进分母？两种等价记账法：

- **剔除法**（"免于考核"的最直读）：免考点**同时移出分子和分母**——发令次数里也不含它。率 = 合格 /（合格 + 不合格非免考）。
- **视为合格法**：免考点算进分子。率 =（合格 + 免考）/ 全部发令。

两种方法**扣罚量完全一致**（都只罚"不合格非免考"那一类），差别只是率值的显示口径。实务/调度考核系统多采用**剔除法**——"免于考核"字面就是"这段不纳入考核基数"。

## 对 VQMS 的含义

判定每个发令点时不能只输出"合格/不合格"二值，得记**三类**：

```
执行合格 / 执行不合格-非免考 / 执行不合格-免考
```

调节合格率统计时：分母 = 执行合格 + 执行不合格-非免考（剔除免考）；分子 = 执行合格。免考点只记日志、不进率、不进罚。
