# VQMS 前端规划与实施路径

> 状态：**规划**。AVC 考核核心算法草稿（`docs/AVC考核核心算法_草稿.md`）已提交 leader 审阅、尚未定稿。本文件给出「在算法等待期，前端能先做什么、该等什么」的判断与落地路径。
> 脚手架：`RuoYi-Vue3/`（Vue 3 + Element Plus + Vite）。CLAUDE.md 约定 VQMS 业务前端落在 `src/views/vqms/`。

## 1. 背景

- 后端考核算法定稿前有一段等待期。前端不依赖算法定稿的部分占**约 80%**——品牌去除、页面骨架、图表组件、查询/筛选 UI、脚手架定制，均可在等待期完成。
- 核心原则：**页面要存在、图表要能画、交互要跑通**这三件事是确定的；只有「合格率/罚款的数字怎么算并展示」依赖草稿口径，留到定稿后接真数据。

## 2. 现状

- 脚手架 `RuoYi-Vue3/` 完整可用（登录/JWT、用户/角色/菜单/字典、Quartz 监控、代码生成等若依原生页面齐全）。
- `src/views/` 下**尚无 VQMS 业务页面**（只有若依的 `system/ tool/ monitor/` 等）。
- 品牌去除计划已就绪（[品牌去除计划_前端去若依.md](../品牌去除计划_前端去若依.md)），执行待 §5 确认项。
- 部署：前端经 nginx 容器提供（host 8080），改源码后须 `docker compose build nginx`（见部署计划）。

## 3. 分类：能先做 vs 该等草稿

### 3.1 现在就能做（不依赖算法定稿）

| 工作 | 为什么不等 | 产出 |
|---|---|---|
| **品牌去除** | 纯可见层替换，与考核算法零耦合，风险低 | 去若依痕迹、换 VQMS 品牌 |
| **页面骨架 + 路由 + 菜单** | 页面要存在是确定的；具体数字怎么算才等草稿 | `src/views/vqms/` 下业务页面 + 侧边栏菜单 |
| **图表组件封装**（ECharts） | 曲线/趋势图怎么画是确定的，画什么数据才等草稿 | 可复用图表组件 |
| **查询/筛选 UI** | 表单交互不依赖算法口径 | 日期范围、母线/机组选择、导出按钮 |
| **脚手架定制** | 纯结构，零算法依赖 | 默认首页 → VQMS 仪表盘骨架、业务菜单 |
| **阈值管理表 UI** | 字段名已定（`busbar_threshold` / 分档 `T_fast`/`T_econ`），与判定逻辑无关 | 增删改查页面 |

### 3.2 该等草稿定稿的（占少数）

| 工作 | 卡在哪 |
|---|---|
| **合格率/罚款数字的口径与展示** | 等草稿定稿（两档平行 + 剔除法是否最终口径） |
| **调节合格率分档可视化**（快速性/经济性分列） | 字段口径依赖草稿；UI 布局可先占位 |
| **免考标注 UI** | 免考遥测可得性本身待定（草稿 §2.8） |

## 4. 落地路径（三阶段）

### 阶段 1 · 品牌去除（零风险，可立即开始）

依据 [品牌去除计划_前端去若依.md](../品牌去除计划_前端去若依.md)。执行前需确认 §5 六项：

1. 品牌名（建议 `VQMS 电压质量管理系统`）
2. logo / favicon（业主提供 or 文字占位）
3. 首页内容（VQMS 简介 or 留空占位）
4. 页脚版权方
5. 内部 `ruoyi.js` 是否彻底改名（默认不改）
6. 后端 banner 是否改（默认不改）

> 可先用合理默认值执行，leader/业主后续微调。

### 阶段 2 · VQMS 业务骨架

- 建 `src/views/vqms/` 目录 + 子页面（日/月/年合格率、电压曲线查询、AVC 投运率、调节合格率、阈值管理）。
- 侧边栏菜单：把若依默认业务菜单换成 VQMS 业务菜单结构。
- 路由配置（`src/router/`）。
- 默认首页换成 VQMS 仪表盘骨架（占位卡片）。

### 阶段 3 · 图表与交互（mock 数据）

- 封装 ECharts 组件：电压曲线（`his_curve_sv`）、合格率趋势、分档柱状图。
- 查询/筛选 UI：日期范围、母线/机组选择、导出按钮。
- **用 mock 数据**跑通仪表盘/曲线/报表的完整交互。
- 草稿定稿 + 后端接口起来后，mock → 真实数据。

## 5. 收益

leader 定稿时，前端壳子、图表、交互均已就绪，只剩「接真数据 + 对口径」——后端和算法的等待期前端不空转，整体交付周期缩短。

## 6. 待确认

- 阶段 1 品牌去除 §5 的 6 项确认（见上）。
- 阶段 2 页面清单是否齐全（日/月/年合格率、曲线查询、投运率、调节合格率、阈值管理）——是否还有其他业务页面？
- 阶段 3 图表类型清单是否齐全。
- 是否现在就进入实施（建议从阶段 1 开始）。
