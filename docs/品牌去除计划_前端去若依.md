# 前端品牌去除计划 — 去若依化

> 目标：移除 RuoYi-Vue3 前端所有"若依 / RuoYi"**可见**痕迹，换成 VQMS 品牌，让业主看不出底层是若依框架。
> 状态：**规划，未执行**。执行前需确认 §5 待确认项（品牌名、logo 等）。
> 排查依据：`grep -i "若依|ruoyi" RuoYi-Vue3/src` + 人工分类 + login.vue/settings.js 确认。

### C. 内部代码（不影响显示，建议不改）

- `src/utils/ruoyi.js`（工具函数文件）+ 约 10 处 `import @/utils/ruoyi`（main.js / request.js / download.js / user.js / HeaderSearch / TagsView / SidebarItem / index.js 等）

- 后端（RuoYi-Vue-springboot3）也有"若依"（启动 banner、application name、swagger title 等），但业主通常只看前端；如需后端也去品牌，另起任务。
