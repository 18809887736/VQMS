核心思路：把这 6 个 yx 当**布尔输入**，列**真值表**（yx 组合 → 期望 yc511/yc512），注入测试值驱动 JS 计算、验证输出编码。本质是组合逻辑测试。

### 正母 yc511 测试用例（控制 yx201/yx202/yx301/yx302）

| 用例               | yx201 1号断路器 | yx202 1号正母刀闸 | yx301 2号断路器 | yx302 2号正母刀闸 | step0 1号正母连 | step1 2号正母连 | 机数 | 带电 | **期望 yc511** |
| :----------------- | :-------------- | :---------------- | :-------------- | :---------------- | :-------------- | :-------------- | :--- | :--- | :------------- |
| ① 空母线           | 0               | 0                 | 0               | 0                 | 0               | 0               | 0    | 0    | **0**          |
| ② 1号并正母        | 1               | 1                 | 0               | 0                 | 1               | 0               | 1    | 1    | **11**         |
| ③ 2号并正母        | 0               | 0                 | 1               | 1                 | 0               | 1               | 1    | 1    | **11**         |
| ④ 双机并正母       | 1               | 1                 | 1               | 1                 | 1               | 1               | 2    | 1    | **12**         |
| ⑤ 断路器合、刀闸分 | 1               | **0**             | 0               | 0                 | **0**           | 0               | 0    | 0    | **0**          |
| ⑥ 断路器分、刀闸合 | **0**           | 1                 | 0               | 0                 | **0**           | 0               | 0    | 0    | **0**          |

**用例⑤⑥是关键**——验证「并网 = 主断路器合 **AND** 刀闸合」的 AND 逻辑（只合一个 → step0=0 → 不算并网）。用例⑦验证 2 号半合（断路器合但刀闸分）不影响 1 号的结果。

### 副母 yc512：完全同构

把表里 `yx202/yx302`（正母刀闸）换成 **`yx203/yx303`（副母刀闸）**，期望输出列改成 **yc512**（母线号=1）。同样的 7 个用例、同样的期望值（0/11/11/12/0/0/11）。

### 怎么「控制」这些 yx（注入方式）

yx 是对端遥信，测试不能真去合断路器，走**数据注入**：

**方式 A — 测试库直注（测 JS 引擎本身）**

1. 测试库 `yx` 表按用例 INSERT 6 个 yx 的 0/1 值（模拟断路器/刀闸状态）；
2. 触发 JS 220/221 执行（对端 JS 引擎读 yx、按 `JS_DATA_STEP` 算）；
3. 读 `yc511/yc512`，断言 = 上表期望值。

**方式 B — L0 单元测试（把 JS 逻辑纯函数化，最快）**
把 step0–5 写成纯函数，喂 yx 组合直接断言编码——不依赖 DB/引擎：

```
// 伪代码
assertEquals(0,  encode(false,false,false,false));  // ①
assertEquals(11, encode(true, true, false,false)); // ②
assertEquals(12, encode(true, true, true, true));  // ④
assertEquals(0,  encode(true, false,false,false)); // ⑤ AND 边界
```

**方式 C — 合成数据工具**
用 `tools/avc-data-gen/` 生成 yx 场景序列（带时间戳的 yx 变位），跑端到端。

### 补充：VQMS 侧的测试（它只读 yc，不读 yx）

VQMS 是 yc511/512 的**只读消费者**，所以 VQMS 侧测的是**解码**，不碰 yx：

| 输入 yc | 解码 带电 | 解码 机组数 | 母线号          |
| :------ | :-------- | :---------- | :-------------- |
| 0       | 0         | 0           | 0(正母)/1(副母) |
| 11      | 1         | 1           | 同上            |
| 12      | 1         | 2           | 同上            |

给 VQMS 喂 yc511/512 这几个值，验证它解出「带电 + 机组数 + 母线号」正确，并正确用到投运率分母 / 判定。
