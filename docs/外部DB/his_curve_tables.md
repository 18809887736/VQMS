## 关键发现

1. **表设计**: 两张表均无主键、无索引，`save_time` 用 `varchar(255)` 而非 `datetime`，查询性能可能受限
2. **数据格式**: 同一时刻（毫秒级）双写两条设备（母线 0+1, 发电机 0+1），可判断为一次采集周期
3. **稳态数值**: 当前 high/low/average 三相一致，说明系统无调节动作，仅持续稳态记录
4. **plan_SV 差异**: `plan_SV=10245` 与 `average_SV=234` 数量级不同，疑似 `plan_SV` 为原始遥测编码值，需通过 `ori_code` 表转换（但该表当前为空）
5. **Cos 单位**: `Cos=127400/114800` 读作 0.1274 和 0.1148，说明 `Cos` 字段实际存储的是 ×1,000,000 后的整数值（即实际功率因数 ≈0.127 和 ≈0.115）
