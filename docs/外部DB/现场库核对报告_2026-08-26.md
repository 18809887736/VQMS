## 三、五大发现（证据内嵌）

### 发现① 目标值形态解码规则被现场数据推翻（最高优先级）

type5 电压指令 **150,177 条全量**（2023-06-16 ~ 2026-08-18，约三年），**100% 目标值形态、0 条增量形态**，obj_num 恒 = `2`：

```
收到远方遥调执行指令:220KV目标值,12315.4.
收到远方遥调执行指令:220KV目标值,22316.7.
收到远方遥调执行指令:220KV目标值,32309.2.
```

- **首位数字 1/2/3 完美均匀轮转**：分布 50,057 / 50,060 / 50,060（偏差 <0.01%，三年 15 万条无一例外）——**轮转码实证，且存在于目标值形态的首位**（不止增量形态第 2 位）
- 去首位后余值 ÷**10** = kV：`1|2315.4` → **231.54 kV**、`2|2316.7` → 231.67、`3|2309.2` → 230.92——与 his_curve_sv 的 plan_SV 实际值域（230.900 ~ 231.700，见发现④）**精确吻合**
- 尾部样例 `12340.`（无小数位）→ 234.0 kV，同样自洽
- 合成库旧样例 `主省220KV目标值,22315.` 按新口径 = 2|2315 → 231.5 kV，同样自洽——**旧"整数 ÷100"解读（223.15 kV）很可能自始是误读**
- 指令间隔 ~5 分钟（偶发 5.5 分钟），与窗口假设吻合 ✓

**对照现行实现**：`VTargetDecoder` 目标值形态按"整数文本 ÷100、无轮转位"解码 → 对现场文本 `12315.4` 会解出 123.154 kV → 包络 [230,236] 永不含目标 → **15 万条指令将全部误判不合格**。

### 发现② 增量形态现场零实例

三年 15 万条指令无一条含"增量"字样；ori_code 原始码表为空。增量解码路径（第 2 位循环码 0~5、幅值 ×100V、t₀ 依赖）**保留但现场无数据可验证**。

### 发现③ yc_history 仅 4 个遥测点——免考/门控/主母线解析现场无源

| yc_num | 行数 | 跨度 | 值特征 |
|---|---|---|---|
| 222 | 86,706 | 2022-12 ~ 2026-08 | 恒 10020 |
| 301 | 86,706 | 同上 | 7300 ~ 92000（机组有功，含小数） |
| 302 | 86,706 | 同上 | 20000 ~ 92000（机组有功） |
| 303 | 86,706 | 同上 | 150000 / 50000 两值 |

- **yx501（免考旗）、yc4001（主母线指示）、yx2003、yx1001、yc216/316 现场库中全部不存在**
- 写入周期 = **15 分钟**（非分钟级）
- 推论：ExemptionApplier（免考）、GateFilter（门控）、主母线指示点解析在**现场数据源下全部无输入**；"yx501 缺失从严按 0"默认口径若照跑 = 全部指令计罚
- 点号核对事项性质升级：原假设"号码待核对"，实际是**信号本身不在该库**——需对端提供真实点号映射或另接信号源

### 发现④ his_curve_sv 存在脏值与第三条母线

- 260 万行中 high_SV 出现 **0.0 值**（坏点；busbar 0/1 值域 0.0 ~ 531.0）——0 值不拦则包络被毒化（low_SV=0 → 包络无限宽 → 误判合格）
- **busbar 2 存在**：705 行，530/531 kV 值域 = **500kV 母线真数据**（合成库只有 0/1）；plan_SV 另见 10538.000 等异常值
- busbar 0：57.6% 行 high≠low；busbar 1：68.0%——窗口摆幅真实存在，包络"夹住"分支可测 ✓
- plan_SV 异常值 10238.000 / 10245.000（busbar 0/1 早期数据）与 230.9~231.7 并存——plan_SV 本身也是废值口径的又一佐证

### 发现⑤ 运行特征与假设的吻合项

- 指令 ~5 分钟间隔 ✓（偶发 5.5 分钟）
- his_curve_sv 双写 busbar 0/1 ✓
- save_time varchar 带毫秒 ✓（格式 `'2021-05-07 15:27:57.556'`，亦有无毫秒形态 `'2023-06-16 11:49:55'`）
- warn_info millisecond 字段与时间戳毫秒位不对应（疑似独立随机值）——落账时照录即可，勿当时间成分

## 四、对 VQMS 代码的影响矩阵

| 组件 | 影响 | 级别 |

| VTargetDecoder（S1） | 目标值形态解码规则与现场格式不符（发现①）——不改则现场回放全量误判 | **阻断级** |
