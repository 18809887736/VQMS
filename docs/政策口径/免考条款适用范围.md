# AVC 免考条款适用范围（仅作用于"调节合格率"）

> 出处：《东北区域电力并网运行管理实施细则》《东北区域电力辅助服务管理实施细则》（东北能源监管局 2024-09-04 印发）附件6「AVC 装置技术指标要求及考核规定」p48 §三。原文存档：[AVC 装置技术指标要求及考核规定.md](AVC%20装置技术指标要求及考核规定.md)

## 结论

**§三「免考」在逻辑上只对 §二「AVC 装置调节合格率」起作用，不作用于 §一「AVC 装置投运率」。** §一 有其独立的免责机制——"扣除因电网原因造成的 AVC 装置退出时间"。两者是**两条平行的免责路径**，服务于两个不同的考核维度，不能混用。

## 文本证据：免考条款的语言只匹配"调节"

§三原文：

> 已经将纳入 AVC 闭环控制的全部无功设备，按照其最大无功功率发出或吸收能力**参与无功电压调节**，但仍不满足 AVC 合格标准……

- "**参与无功电压调节**" → 调的动作，正是 §二（调节合格率）的考察对象
- "**最大无功功率发出或吸收**" → 调无功去够电压目标，对应 §二 的"调整到合格区间"
- "**仍不满足 AVC 合格标准**" → 电压/无功没够到合格区间

整句描述的是"**调了、尽力调了、还是没调到位**"——与 §二（指令下达后 1 分钟内是否调到合格区间）完全对应，与 §一（AVC 装置在不在线）无关。

## §一 投运率自带独立免责（与 §三 无关）

§一原文：

> 在计算 AVC 装置投运率时，**扣除因电网原因造成的 AVC 装置退出时间**。

投运率的免责是**时间扣减**：电网原因导致 AVC 退出在线的时段，从投运时间的分母里扣除。

## 两套机制的差异

| | §一 投运率 | §二 调节合格率 |
|---|---|---|
| 考察什么 | AVC 装置**在不在线**（时间记账） | **调得到不到位**（电压/无功效果） |
| 不达标的原因 | 装置退出（故障 / 检修 / 电网断开） | 调了但没够到合格区间 |
| 免责机制 | 扣除电网原因退出**时间**（§一 自带） | 尽力仍不达标免**该时段**（§三） |
| 判定数据 | AVC 投退 yx 信号 + 退出原因标注 | 设备级无功遥测 Q vs 极限值 |

## 为什么两者必然分开

§三 的前提是"无功设备在**参与调节**"——这预设 AVC 在线运行。若装置已退出（不在线），根本不存在"参与调节"，§三 的前提不成立，无从免责。换言之：投运率不达标的场景是"退出"，调节合格率不达标的场景是"调不够"，**二者互斥**，所以免责机制必然各走各的。

## 一点保留

§三 原文写的是"AVC 合格标准"泛称，**没有明写"仅针对 §二"**，严格咬文嚼字上存在微弱歧义。但综合三点：

1. 语言只描述"调节"动作；
2. §一 已有独立免责机制（再套用 §三 会重复 / 矛盾）；
3. 工程语义（退出 vs 调不够互斥）。

电力行业实务通行解读即：**§三 专属 §二；§一 用自己的"扣除电网原因退出时间"。** 两者共同精神是"非厂站原因不罚"，但分别服务两个维度。

## 附：『最大无功功率发出或吸收能力』的概念

§三 免考判定的核心是"无功设备是否顶到**最大无功功率发出或吸收能力**"。这个概念是整个免考机制的判定基准，须先厘清。

### 无功的两个方向与对电压的作用

无功功率 Q（VQMS 规范单位 **kvar**；下文示例沿用行业铭牌习惯用 Mvar，换算 **1 Mvar = 1000 kvar**）有**两个方向**，每个方向各自有上限：

| 方向 | 含义 | 等效 | 对电压 |
|---|---|---|---|
| **发出**（Q>0，容性 / 超前） | 往电网**注入**无功 | 电容器 | **升压** |
| **吸收**（Q<0，感性 / 滞后） | 从电网**吸取**无功 | 电抗器 | **降压** |

每台设备的双向极限记作 **Q_max_发**（发出上限）与 **Q_max_吸**（吸收上限），二者通常不等、各自独立。

### 免考判定的方向匹配规则

判定"尽力"必须**方向正确 + 顶到极限**：

- 电压**偏低**（over-low）→ 需升压 → 设备应**发出**无功 → 检查是否顶到各设备的 **Q_max_发**
- 电压**偏高**（over-high）→ 需降压 → 设备应**吸收**无功 → 检查是否顶到各设备的 **Q_max_吸**

方向错（如电压偏高却在发出无功）或留余力（某台没顶到极限），均不算尽力，不免考。

### 各类设备的无功能力来源

| 设备类型 | 无功来源 | 能力特征 |
|---|---|---|
| **同步发电机 / 调相机** | 励磁电流（过励磁→发出） | **不对称**：过励磁强、欠励磁弱；极限随 P 变（P-Q 能力曲线） |
| **双馈/全功率风机、光伏、储能（逆变器型）** | 变流器四象限运行 | **对称**：`±√(S²−P²)`；P=0 时仍可调（STATCOM 模式） |
| **SVC / STATCOM** | 电力电子投切 | **对称**：±额定（连续可调） |
| **电容器组** | 固定容性 | **单向**：只能发出，铭牌 kvar（且 Q∝V²） |
| **电抗器** | 固定感性 | **单向**：只能吸收 |

### 同步发电机的能力曲线（举例）

同步发电机存不了单值极限。以 300MW 汽轮机（353MVA / 0.85pf）为例：

- 额定无功 Q_N = S·sinφ = 353×0.5268 ≈ **186 Mvar**（精确可算，额定工况点）
- 过励磁极限（励磁电流圆）：随 P 变，P≈250MW 时约 **+220 Mvar**，P=0 时理论 ~290 Mvar
- 欠励磁极限（端部发热 / 静稳）：约 35–40% S → **−130 Mvar** 量级

`+220 / −130` 是典型代表值，依赖该机出厂的 **P-Q 能力图**（参数 X_s 等），**不能仅凭铭牌算出**。

### 逆变器型主体（风机 / 光伏 / 储能）

无功能力由变流器视在容量 S 决定，双向对称：

```
Q_available = ± √(S_converter² − P²)
```

- 满发时受 S 约束（如 5MW / 5.5MVA 机满发可 ±2.29 Mvar，≈0.91 pf）
- 低发 / 零发时余裕增大，可调无功反而更多（这是同步机做不到的）
- 风电场整体 = Σ(各风机) + 升压站集中补偿（SVC / STATCOM / 电容器 / 电抗器）

### 关键结论

**"最大无功功率发出或吸收能力"不是常数，而是按设备类型分别建模**：同步机是随 P 变的能力曲线、逆变器是 `±√(S²−P²)` 对称圆、电容/电抗单向、SVC/STATCOM 连续对称。免考判定要逐台采实测 Q、按各自极限比对，再汇总判定"全部设备是否在正确方向顶满"。

## 对 VQMS 实现的含义

免考判定是**两条独立代码路径**，不能合并：

```
投运率免责：
  判定 "AVC 退出时段" 的退出原因 ∈ {电网原因}
  → 从投运时间分母扣除
  数据：AVC 投退 yx 信号（yc_history 门控点）+ 退出原因标注

调节合格率免责：
  判定 "不合格时段" 是否满足
    全部 AVC 闭环无功设备 在正确方向（偏低→发出 / 偏高→吸收）顶到极限
  → 该时段免考
  数据：每台设备实测无功 Q vs (Q_max_发, Q_max_吸) 配置值
```

### 免考点在调节合格率里怎么记账（三状态模型）

严格按附件6 §二：`执行合格点数` = "指令下达后 **1 分钟内**调到合格区间"的发令点数。**免考 ≠ 合格**——免考是把"不合格但不罚"单独拎出，**不把不合格翻成合格**。故每个发令点须记三类状态，而非二值：

| 状态 | 条件 | 计入 `执行合格点数`？ | 是否扣罚 |
|---|---|---|---|
| **执行合格** | 1 分钟内调到合格区间 | ✅ 是 | 不罚 |
| **执行不合格（非免考）** | >1 分钟、且不满足免考条件 | ❌ 否 | ✅ 罚 |
| **执行不合格（免考）** | >1 分钟、但全部无功设备已正确方向顶满仍不达标 | ❌ **否** | ❌ **不罚** |

**记账法（剔除法，实务通行）**：免考点"免于考核"= **同时移出分子与分母**：

```
调节合格率 = 执行合格 / (执行合格 + 执行不合格-非免考)
            （免考点剔除，不计入发令次数基数）
扣罚量 = 仅对 "执行不合格-非免考" 计
```

> 另一种等价记账是"视为合格法"（免考计入分子），与剔除法**扣罚量完全一致**，仅率值显示口径不同。VQMS 统一采用**剔除法**（贴近"免于考核"字面）。

**实现要求**：每个发令点的判定输出不能只给合格/不合格二值，须带状态分类（执行合格 / 执行不合格-非免考 / 执行不合格-免考）。调节合格率统计时，免考点只记日志、不进率、不进罚。

注意：调节合格率免责的实现门槛远高于投运率免责——前者需要设备级无功遥测可见性 + 每台设备的双向极限配置；而发电机类设备的极限还是**随 P 变的曲线**（非单值），电容器/电抗器是单向、SVC/STATCOM 是连续值，逆变器型（风机/光伏/储能）是 `±√(S²−P²)`——配置表得按设备类型分别建模。若 VQMS 只读得到 `his_curve_sv`（纯电压曲线）、拿不到设备级无功遥测，则**调节合格率免责无法自动判定**，只能输出"电压不合格时段"，免责与否留人工或上游系统判定。
