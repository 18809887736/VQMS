## 1. 调度的指令（发令事件）

电压或无功指令。本项目**暂时只考虑电压指令**，无功指令留有接口以便后续开发。

**来源：`warn_info` 表**（注：**不从 `his_curve_sv.plan_SV` 获取**）

| 字段        | 含义             | 备注               |
| ----------- | ---------------- | ------------------ |
| `warn_type` | 通常为 `5`       | 现场人员整定       |
| `obj_num`   | 对象编号         | 现场人员整定       |
| `warn_info` | 目标值 或 增量值 | 文本内含数值，见下 |

指令有两种形态（`warn_info` 文本示例）：

- **增量值**：`收到远方遥调执行指令:辽宁母线电压增量指令编码值处理,2202.`
  - 编码 `2202` 解码（左起 4 位）：
    - **第 1 位 `2`** —— 方向：`2` = 增加，`1` = 减少
    - **第 2 位 `2`** —— 循环码（具体含义待确认）
    - **第 3–4 位 `02`** —— 增量幅值，每单位 100V → `02` = **200V**
  - ⇒ `2202` = **电压增加 200V**
  - 💡 **增量值 + 当前实时母线电压 = 绝对目标值**（与"目标值"形态殊途同归）。例：当前电压 `234.25 kV` + `0.2 kV`（200V）= 目标 `234.45 kV`。两种指令形态最终都产出一个绝对目标电压。
- **目标值**：`收到远方遥调执行指令:主省220KV目标值,22315.` —— 代表 **223.15 kV**
- 其他类型：预留

> 一条指令由（`warn_type`、`obj_num`、目标值或增量值）表征。本项目给个初始值后，保留 **CRUD 的读取、更新**功能。

# 四、数据缺口核对（对照 [AVC考核核心算法_草稿.md](AVC考核核心算法_草稿.md)）

把核心算法每一步需要的数据，对照上文一~三节现有数据源，结果：调节合格率主判定够用，但投运率 / 免考 / 考核量存在 4 个缺口。

| 算法步骤 | 需要的数据 | 现有数据源 | 结论 |
|---|---|---|---|
| 调节合格·解码目标电压（目标值形态） | `warn_info.warn_info` 文本 | ✅ 有（`warn_type=5`） | 够 |
| 调节合格·解码目标电压（增量形态） | 增量编码 + 当前实时母线电压 | ✅ 编码有；实时电压 = yc_history 母线电压点 | 够 |
| 调节合格·按主母线分组 | 主母线号 | ✅ 有（yc_history 主母线号点） | 够 |
| 调节合格·每分钟 high/low | `his_curve_sv.high_SV`/`low_SV` | ✅ 有 | 够 |
| 调节合格·基准时刻 t₀ | `warn_info.warn_time` | ✅ 有 | 够 |
| 投运率·AVC 投退 | yc_history 投退点（`yc_data` 1/0） | ✅ 有 | 够 |
| **投运率·并网运行状态** | **并网主体并网信号** | ✅ **有**：JS 算的 `yc511`/`yc512`（[JS_并网与母线号.sql](外部DB/JS/JS_并网与母线号.sql)） | **已补** |
| **投运率·退出原因** | **AVC 退出原因（电网 vs 非电网）** | ❌ **无** | **缺口②** |
| **调节合格·免考判定** | 每台 AVC 无功设备实测 Q + 双向极限 (Q_max_发, Q_max_吸) | ❌ **无设备级无功遥测** | **缺口③** |
| **考核量计算** | 并网主体**额定容量**（千瓦） | ✅ **有**：`GENERATOR.ratingPPower` Σ = 600000 kW（定值） | **已补** |

## 缺口说明

- **缺口① 并网运行信号**（投运率分母）：✅ **已补**。由对端 JS 引擎算好的 `yc511`（正母单元信息）/`yc512`（副母单元信息）提供（见 [JS_并网与母线号.sql](外部DB/JS/JS_并网与母线号.sql)、[JS计算引擎说明.md](外部DB/JS计算引擎说明.md)）。编码 = 带电(1/0)×10 + 并网机组数(0/1/2)；**电厂并网 = `yc511≥10` OR `yc512≥10`**（任一母线带电即并网运行）。该值由对端据 `BUS_GEN_LINK_LOGIC_DEV` 的机组-母线开关拓扑（yx201/202/203、yx301/302/303）周期性求值得出，VQMS 直接读结果即可。
- **缺口② AVC 退出原因**（投运率免责）：投运率免责要"扣除**电网原因**退出时间"。现有投退点只告知"AVC 退了"，**不告知为何退**（电网原因 / 设备故障 / 检修）。区分不出则无法扣减。可能 `warn_info` 告警类型（如"AVC 调节闭锁""数据错误闭锁"）可映射，待确认。
- **缺口③ 设备级无功遥测**（调节合格率免考）：免考要判"全部 AVC 无功设备**已正确方向顶到极限**"，需每台设备实测 Q + (Q_max_发, Q_max_吸)。现有数据只有站级母线电压、总有功，**无设备级无功**。拿不到则**免考无法自动判定、留人工**（见 [免考条款适用范围.md](政策口径/免考条款适用范围.md)）。
- **缺口④ 额定容量**（考核量）：✅ **有数据**，是**定值**。并网主体全厂总额定 = `Σ GENERATOR.ratingPPower` = 300000 + 300000 = **600000 kW**（2 台 300MW 机组）。VQMS 处理方式：给个**初始值**（取自配置库 Σ）后，建配置项**保留 CRUD 的读取、更新**功能（运行人员可在系统里改，如增容改造后更新），不写死代码。考核量公式：`缺额百分点 × 额定容量(万千瓦) × 0.02`。

## 结论

- **调节合格率主判定**（high/low 包络判目标电压）：**数据够用** ✅
- **投运率**：缺口① ✅ **已补**（yc511/yc512）；仍缺 ②（退出原因）→ 分母可算、免责待定
- **免考**：缺 ③ → **无法自动判**（留人工）
- **考核量**：缺 ④ → ✅ **有数据**（定值 600000 kW），VQMS 给初始值 + 保留 CRUD 读写
