- **缘起（架构）**：调节合格率/投运率需要日/月/年汇总。v3.4 曾建分钟级 `voltage_quality_daily/monthly/yearly` + `precompute_cursor`，判定改指令级口径（2026-08-13 拍板）后**整套废弃**——旧部署残留见 `sql/5.0/backup/ry_vqms.sql`。
- **为什么不能查询时算**：判定 CPU 毫秒级不是问题，卡在 I/O——`his_curve_sv` 无索引（每次过滤=对端生产库全表扫）+ 年页单次视图需拉 ~105 万行曲线（~80MB 过网，5~20s），且查询时重算会让历史报表随 `T_fast` 等参数改动变脸，考核数字不可审计。日页勉强可、月临界、年不可行 → 必须预计算冻结结论。
- **解决路径**：**搁置轨 S2~S4，以后再加**（2026-08-20 Leo 确认）。统计 DDL 列被三个未决项吊着（策略丁档标记列 / `T_fast` 默认值 / `invalidTiers`·免考汇总呈现），现在设计=猜。确定轨已预留全部接口面：`vqms_command_ledger` 全量流水（解封后可全历史重算）、`RegulationJudge` 接口、策略参数表、Quartz 脚手架。
