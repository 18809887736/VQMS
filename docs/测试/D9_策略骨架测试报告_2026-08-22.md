## 二、交付物与设计要点

### 2.1 类型契约（statistics 包，12 类）

- **`RegulationOutcome`**（sealed）：`Judged{fast/econ: Optional<Verdict>, completeness∈[0,1], invalidTiers}` ∪ `Undecodable{reason}`。构造期不变式「档 VERDICT 为空 ⟺ 该档 ∈ invalidTiers」compact constructor 强制（违背即 IAE）；Undecodable 不携带 completeness——两类信息互斥由 sealed 结构性排除。
- **`StubRegulationJudge`**（确定性 stub、禁随机、`isStub()=true`）——契约级为真 vs 算法核心占位的切分线：
  - **为真**（输出契约稳定面，D9 完成标准要求）：解码**分类**（目标值/增量形态识别 + 三类归因，只判"能不能解"、不算 V_target 数值）、completeness（[1..t_econ] 有数据分钟占比）、invalidTiers 两成因（整档全缺 / 聚合后 L>H，草稿 §2.6 同口径）；
  - **占位**：有效档 VERDICT 一律 QUALIFIED（不保证正确，S1 替换点）；
  - 分类优先级：结构脏写 → 循环码非法（第 2 位 ∉ {0..5}）→ 方向非法（脏写）→ 缺 t₀（'9X02' 双向坏按循环码归因，对齐策略文档 §4.1 例 #4）。
- 输入侧 `AvcCommand`/`MinuteCurve`/`JudgeParams` 为 record；`RegulationJudge` 接口签名照 v5.0 §8.2，解码留在实现内部。

### 2.2 参数化策略骨架

- **`DataUnavailabilityPolicy.evaluate(outcome, config)`** 纯函数：四桶 `Disposition{COUNT_NORMAL, EXCLUDE_REPORTED, COUNT_UNQUALIFIED, PEND_MARKED}` 恰落其一；评估优先级 Undecodable → invalidTiers 非空 → completeness<1（EXCLUDE 时按阈值）→ 正常。甲/乙/丙/丁 = 四组配置向量，**只存在于测试侧**（对抗验证吸收后自 main 移除，v5.0 §8.6「不硬编码进任何代码」字面兑现）。
- **`vqms_policy_param`** 表（param_value varchar、约定键 ×4、零种子行=选套留空拍板、无 CHECK 钉值、无 CRUD UI、无缓存——均为范围拍板或有意取舍）；`VqmsPolicyParamService.loadConfig()`：空表/缺键 → `Optional.empty()`（未定稿态不猜默认值），值非法/缺阈值行 → `IllegalStateException` 显性失败。

### 6.2 已驳回（对抗核实不成立，留档）

部分键缺失降级 empty（javadoc 明文 API 契约 + 选套留空拍板一致）；阈值行残留静默忽略（evaluate 不读该值，行为无损）；completeness=0 ∧ invalidTiers 空（语义矛盾态但生产者不可达，record 允许是为乙档主战场输入留门——completeness=0 必伴双档无效，构造器组合自由度属类型层取舍）；updateValue 无生产调用方（死方法论据不足，已顺带参数化）；JudgeParams 不钉政策值域（来源 vqms_judge_param 有 DB CHECK + Service 双层校验，(4,4) 退化态由上游挡）；exactlyOneBucket 属性空洞说（total 性检查拦截漏臂 switch/map.get null，非恒真）；judged_semantics_hold 镜像说（另有 VectorTest 独立 oracle 互证）；UNVERIFIED 标注判据不一（实现判据=「期望行为依赖未实证假设」，四处未标用例均有已定稿参照背书）。

### 6.3 已知边界（声明，不修）

- 场景 IT 参数取生成器布局 (5,30)，生产种子 (4,5) 对齐随真实数据回放（测试方案登记在案）。
- 阈值边界 ≥ 方向取策略文档口径，两份权威文档冲突随选套拍板收口（⚠ UNVERIFIED-口径 已标注）。
- 循环码轮转规律待生产实证——分类规则只用已拍板值域 {0..5}，自造用例全部带 ⚠ 标。
- judge 接口当前无生产调用方（编排随 S4 Quartz）——接口面属 v5.0 §8.2 拍板的预留，非死代码。
