## 二、交付物与设计要点

### 2.1 main（新增 6 类 + stub 重构 + yml）

| 类 | 要点 |
|---|---|
| `statistics/VTargetDecoder` | `classify(cmd)` 三类失败归因（脏写→循环码→方向→t₀ 校验序，'9X02' 归循环码非法）+ `decode(cmd)` 数值计算。**2 位小数收口**：double 加法尾差（234.8+0.2=235.00000000000003）会把整数边界档误判越界——收口后数学上无 .xx5 中点，与 Python round 无分歧路径（哨兵用例 + 差分 fixture 双佐证） |
| `statistics/EnvelopeAggregator` | `aggregate(curves, lo, hi) → Optional<Envelope{low,high}>`——min(low)/max(high)；空窗=empty、L>H 原样上报不判定，两者由 judge 映射 invalidTiers |
| `statistics/DefaultRegulationJudge` | 注册 ID `V1_0`：解码 → completeness 如实（[1..t_econ] 占比）→ 两档平行包络夹住判定（闭区间 L≤V≤H）。纯函数零 Spring 依赖 |
| `statistics/RegulationJudgeConfig` | 注册表：`@Bean("STUB")`/`@Bean("V1_0")` + `@Primary` 选择 bean。fail-fast 三路：未配置 / 未知 ID / 重复 ID（bean 重名，Boot 默认禁覆盖）；生效 ID 进启动 INFO 日志（审计落点）；加变体=加一类一 Bean 行 |
| `source/reader/YxSignalReader(+Impl)` | 阶跃保持契约 `heldValue(pointNum, atMinute)`——取 ≤ 当分钟最近一条；实现经 SourceReader.readYc（D4 闸门+SLAVE 路由），选取逻辑为包内纯函数 `selectHeld` |
| `statistics/GateFilter` | 门控前置过滤：启用点（`gate_enabled=1` ∧ type=yx）全部保持值=1 才判；**无启用点直通**（拍板空转语义，种子 3009/2003 均 0）；构造器注入可 mock |
| `StubRegulationJudge` | 分类逻辑上移 Decoder（行为等价），占位结论不动 |
| `application.yml` | 增 `vqms.judge.algorithm: STUB`（显式配置联调期默认；上线切 `V1_0` = 改配置+重启，v5.0 §8.8.5） |

## 四、实现决策声明（依例明示）

1. **decode 2 位小数收口**：非文档明文而是实现选择——动机=消除 double 尾差翻转整数边界档判定（哨兵用例锁定）；增量幅值粒度 0.1kV 保证不存在 .xx5 中点，故与 Python `round(x,2)` 无分歧路径（差分 fixture 实证 20/20 一致）。
2. **EnvelopeAggregator 返回 `Optional<Envelope>` 而非命名 TierEmpty 类型**：§8.8.2 契约签名示意落地简化——empty 语义唯一（整档缺），sealed 变体属过度构造；L>H 仍在 Envelope 内原样携带。
3. **impl 类保持零 Spring 注解**：Stub/Default/Decoder/Aggregator 均纯类，注册集中在 `RegulationJudgeConfig` 一个文件——「加变体=加一个类」落在一处，纯函数层纪律（§8.8.1）不被注解污染。
4. **YxSignalReader 回看窗固定 1 天**：阶跃保持量变化稀疏的 ponytail 简化；若现场出现 >24h 静默漏读，改常量或下沉 SQL 倒查 LIMIT 1（类内 `ponytail:` 注释留痕）。
5. **GateFilter 多点 AND + 缺失从严拦截**：启用点全部=1 才判、信号缺失视同不满足——考核系统宁可不判（走策略层记账）不可误判；「就地模式是否拦截」等真实语义随置 1 联调核对（现 gate_enabled 全 0 空转，不影响生产行为）。
6. **D9ScenarioContractIT → S1ScenarioContractIT 就地升级**（旧文件删除，git 留史）：stub 形状断言由 StubDecodeClassificationTest 承担；新 IT 含 EXEMPT 两段式（judge 层 PENALIZED + 免考层读真实 yc501 应用得 EXEMPTED，两段分别断言，§4.2 映射表字面执行）。
7. 其余无偏离。
