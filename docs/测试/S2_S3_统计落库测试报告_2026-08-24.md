## 二、六项拍板落点对照

| # | 拍板 | 落点 |
|---|---|---|
| ① | disposition 一列通吃四桶 + rollup 披露计数 | 明细 `disposition varchar(32) NULL`；daily/monthly/yearly 加 `pended_count`/`excluded_count` |
| ② | t_fast 维持 4 + 快照列 | 种子不动；明细 `t_fast_snapshot int not null` |
| ③ | rollup 存计数、呈现归前端 | 三张 rollup 表只含计数列与 completeness_sum（加权还原），零比率列 |
| ④ | algorithm_id 明细必带 + 混合='MIXED' | 明细 `algorithm_id not null`；rollup 行同列，rollup SQL 用 `case when count(distinct algorithm_id)=1 then min(algorithm_id) else 'MIXED' end`（IT 断言单算法周期记 'V1_0'） |
| ⑤ | busbar_group 加容量列 | `rated_capacity_kw decimal(12,3) default null` + domain/mapper 同步 |
| ⑥ | NULL=策略未生效 | disposition 列注释钉死「NULL=选套前只记不判」，无默认桶 |

存储切分自查：全部为派生统计（可从 ledger 流水 + 外部源重算），分钟级分类不落主库——§4 铁律守住。

## 三、口径对照与实现决策声明

1. **rollup 只存计数**：率/罚款快照仅 runtime 三表存（RuntimeStatistics 纯函数单一来源写回，月/年由合计分钟重算非平均日值）；调节侧两链（披露合格率/罚款缺额剔免考与否）属 S5 待拍板——counts 足够两条链各自推导，DDL 不预支结论。
2. **runtime rate_pct 可空**：NULL=零并网分钟（无可考核基数），区别于真 0%——沿 S3 报告声明的全 0 约定。
3. **uk 同宽 varchar(255)**：warn_time/millisecond 不收窄（D8 教训：insert ignore 下收窄会静默截断造假碰撞）。
4. **投运率表不带 algorithm_id**：投运率纯函数无变体注册诉求（§8.8.5 S 轨注 YAGNI），真出现变体时同模式复制。
5. 其余无偏离。
