## 一、执行摘要

S3 纯函数半边交付：`RuntimeMinuteClassifier`（逐分钟投运状态四分类，真值表全矩阵）+ `RuntimeStatistics`（投运率/缺额/考核量，手算向量）。与 S2 同批构成搁置轨统计纯函数层主体。落库 DDL + rollup 半边仍待设计时补。

**附带修复（D4 潜伏 flake，本轮回归踩中）**：`SaveTimeGatePropertyTest` prop④ oracle 精度错位——期望侧用纳秒精度 `LocalDateTime` 判落窗、闸门入参经 `MINUTE_TEXT` 文本天然截秒，生成器允许边界带非零纳秒时两侧判定错位（踩中样本 start=1600-01-01T00:00:00.000000001）。修法 = oracle 边界 `truncatedTo(SECONDS)` 后再喂两侧（测试内注释已留痕）。jqwik 每轮随机种子，此前 D4~S2 各轮全绿属种子未踩中，非无此缺陷。产品代码零改动。

## 二、交付物与设计要点

### 2.1 main（statistics 包新增 4 类）

| 类 | 要点 |
|---|---|
| `RuntimeMinuteState` | 四态 {IN_SERVICE, EXIT_GRID, EXIT_NON_GRID, OFFLINE}——OFFLINE 不计任何分钟 |
| `RuntimeMinuteClassifier` | `classify(onGrid, avcIn∈{0,1}, exitReason∈{0,1,2})`——并网∧投=IN_SERVICE；并网∧退按原因分流（1=电网免责/2=非电网扣罚）；值域校验先于 OFFLINE 短路（垃圾输入不放行） |
| `RuntimeMinuteCounts` | 四计数 record（构造期拒负数）；`onGridMinutes()`=投运+全部退出（不含 OFFLINE）；rollup 对计数求和、绝不平均率列 |
| `RuntimeStatistics` | `summarize(counts, ratedCapacityKw) → RuntimeRateResult`——率=投运/(投运+非电网退出)；缺额=max(0, 99−率)；罚款=缺额×万千瓦×0.02 分；99% 阈值为政策原文写死常量 |

### 2.2 test（新增 2 类 22 用例）

| 测试类 | 用例 | 覆盖 |

## 三、口径逐条对照（正式 v1_0 §1.5 / §5.0 矩阵）

| 口径要求 | 落点 | 断言 |
|---|---|---|
| 未并网不计任何分钟 | OFFLINE 不进分子分母也不进 onGridMinutes | 真值表 6 行 + offline_neverEntersMath |
| 电网原因退出从分母扣除（免责） | 分母 = inService + exitNonGrid | gridExit_exemptedFromDenominator_nonGrid_not |
| 缺额 max(0,…) 封底 | Math.max(0, 99−rate) | 达标向量 shortfall=0；边界恰 99 免罚 |
| 合格标准 ≥99% | PASS_THRESHOLD_PCT=99.0 写死 | boundary_exactly99_noShortfall |
| 考核单价 0.02 分/万千瓦线性 | 与 S2 同公式 | handVector_belowThreshold_penalty（0.6 分） |
| 阶跃保持语义/就近取整 | reader/调用方职责（YxSignalReader ≤当分钟最近一条），分类器只收保持值 | 组件边界声明，非本层用例 |

## 四、实现决策声明（依例明示）

1. **⚠️ 矛盾态从严映射**：「已退但退出原因=未退(0)」（对端 JS 引擎滞后/未部署）→ 归 EXIT_NON_GRID 计罚——免责须有正向电网原因证据，缺证据不免责。合成库 points.yaml 三值语义（0=未退/1=电网/2=非电网）下该态属矛盾/滞后，真实数据核对与信号合理性校验分轨落地后复核本映射（v5.0 §14-8 同族）。
2. **零并网分钟约定**：无可考核基数 → 率/缺额/罚款全 0（不经 max(0,99−0) 罚出 99 点）；报表 NULL 呈现由调用方定。
3. **信号缺失不在分类器内处理**：YxSignalReader empty 的处置归策略族，调用方决定喂入值。
4. 其余无偏离。99% 无现场整定诉求故为常量（对照 t_fast 的可整定定位）。
