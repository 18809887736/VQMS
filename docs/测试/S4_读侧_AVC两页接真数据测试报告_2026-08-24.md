## 二、实现决策声明

1. **daily/monthly/yearly 三端点维持占位**（建议 B）：旧分钟级电压合格率模型已废，三页语义悬空——等真实数据回放后拍板改造方向，本轮不预支。
2. **投运侧率直出快照不重算**：rollup SQL 已按合计分钟重算（Slice3），Service 只透传；调节侧率/罚款由计数经纯函数换算（表里无率列，天然无平均率风险）。
3. **容量未配置的读侧展示口径 = 罚款 0、率照算**（记账侧 runtime_daily 存 NULL 快照）；与「补录前不产罚款数」的容量列注释一致。
4. **审计字段透出**：调节月行带 algorithmId——MIXED 周期在前端可见（决策④ 的展示面）。
5. 其余无偏离。
