## 二、实现决策声明

1. **Redis 写穿但读路径暂不走缓存**：loadConfig 仍直读 DB（D9 行为不变，无热路径消费者）；缓存按 §8.7 apply 规格先建，S4 Pipeline 接策略层时改走缓存读取。
2. **乙自定义阈值的宽容匹配**：三模式键对上但阈值≠默认 → selectedCode=YI 且状态标注「阈值自定义 N%」，不误报未选套。
3. **perms 守卫扩展**：D5PermsConsistencyTest 清单登记两枚新 perm + 新控制器——守卫当场抓到前端漂移（apply 未登记），登记后四方对齐，防漂移机制自证有效。
4. **L3 冒烟待联调批**：页面需登录态 + 后端 API，本机无全栈；人工冒烟清单 = 登录 → VQMS管理→策略参数 → 三态横幅 → 选卡片 → 应用 → 参数表刷新 → 换套日志。
5. 其余无偏离。
