## 一、交付物

### 纯函数层（`ruoyi-vqms/src/main/java/com/ruoyi/vqms/statistics/`）

| 类 | 职责 |
|---|---|
| `PolicyAtom` | 原子条件枚举 A1/A1A/A1B/A1C/A2/A3/A4 + 事实轴归属（Axis 三轴对齐 PolicyConfig 三模式键）；A5 刻意缺席 |
| `PolicyExpression` | 表达式不可变树（AtomTerm / GroupTerm，NOT 限原子或括号组）+ eval + canonical（符号连接词、可原样重解析）+ referencedAtoms |
| `FreeformPolicyParser` | 规则行 DSL 解析（`表达式 -> 动作`）：同层混用须一层括号、嵌套上限一层、!! 拒绝、未知原子/A5 带指引报错 |
| `FreeformRule` / `FreeformPolicyConfig` | 规则记录（ruleId R001…）与生效配置（规则表 ≤16 条 + 全局 τ∈[0,100]） |
| `FreeformPolicyEvaluator` | 首中即断求值 → `Decision(disposition, ruleId)`；全不中兜底 COUNT_NORMAL(ruleId=null) |
| `FreeformPolicyValidator` | fail-fast 校验：空表/超上限/逐行解析(带行号)/重复表达式/COUNT_NORMAL 仅当触发含 A3/存储长度 ≤255 |
| `FreeformPolicyReducer` | 等价规约（§3.3.4 落地件）：轴分区 + 轴序同构检查 + 白名单形状 → Optional(PolicyConfig, 预设名)；保守拒绝 |

### 接入层

| 位置 | 改动 |
|---|---|
| `VqmsPolicyParamService` | 新键族 `freeform_rule_001..N` / `freeform_threshold_pct`；`applyFreeform`（校验→整组 upsert→写穿缓存→规约提示）；`loadFreeformConfig`（损坏显性 ISE，不静默降级预设）；`currentState` 戊分支（selectedCode=WU + 规则回填 + ≡提示）；`applyPreset` 反向清理自由组合键族（单选生效，任意时刻恰一套生效） |
| `RegulationPipeline` | 策略预取提至循环外；自由组合键族存在即优先路由 `FreeformPolicyEvaluator`，预设休眠；皆缺 → disposition NULL 只记不判（原语义不变） |
| `VqmsPolicyParamController` | 新端点 `POST /vqms/policyParam/applyFreeform`（perms 复用 `vqms:policyparam:apply`，@Log 留痕） |
| 前端 `policyparam/index.vue` + `api/vqms/policyParam.js` | 第五卡片「戊·自定义」+ 规则编辑对话框（语法说明/τ 整定/已生效规则回填）+ applyFreeform API |

**存储设计**：零 DDL——复用 `vqms_policy_param` 行式 KV（param_value varchar(255)，校验器守长），每条规则一行紧凑 DSL 文本。§6 第 8 条分母口径冲突未解不影响本落地：EXCLUDE_REPORTED 动作域与现行乙档同源同 UNVERIFIED，复核收敛时按 §3.3.5 第 1 条同步收窄校验即可。

## 四、开发期缺陷自捕（修复后全绿）

1. **parseGroupContent 连接词消费后漏 `pos++`**——组内第二个操作数起全部误判（jshell 最小复现定位）；javadoc 注释与代码不一致类问题，静态推演难中，最小复现一击即中。
2. **规约器把「轴上有规则但形状不规约」静默兜底成默认模式**——违背保守性原则，改为整体拒绝。
3. **canonical() 输出枚举名连接词（"OR"）不可被解析器重读**——改符号 `&`/`|`，保证存储值可回读。
4. **测试数据自身违反 COUNT_NORMAL↔A3 约束**（解码轴配正常记账）——约束正确性复核后确认文档口径成立（无判定结论无可记账），测试服从设计。

## 五、偏离与遗留声明

- **Service 持久化路径（applyFreeform 落库/清理/装载）无 L0 单测**：mapper/Redis 全 mock 化收益低，沿用 S5 先例归入 IT/联调批（`D9PolicyParamIT` 同库直连模式可扩展）；
- **L3 人工冒烟待联调批**：前端对话框交互需登录态与服务器联调（部署侧尚为旧构建），本报告不含浏览器验证；
- **A5 子表、命中规则 ID 列、分母口径冲突收窄校验**三项随对应拍板批次排期（§3.3.5 清单）。
