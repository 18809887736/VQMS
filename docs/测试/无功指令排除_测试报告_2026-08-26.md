# 无功增量指令排除出调节合格率分母 — 测试报告

**日期**：2026-08-26　**范围**：`ruoyi-vqms` statistics 包　**性质**：口径补丁（防未来误判）

## 1. 背景与拍板

对端实时库 `BUSBAR_PLANTYPE` 字典考据（存档 `docs/外部DB/BUSBAR_PLANTYPE.sql`，2026-08-26 导出）揭示指令三形态：0=电压目标 / 1=电压增量 / **2=无功增量**。现行 `VTargetDecoder` 仅电压两形态路由——无功指令尾码若恰为 4 位合法编码，会被误当电压增量解出无意义 `V_target` 进入电压考核，产生随机结论乃至错误罚款记录。

**Leo 拍板（2026-08-26）：以指令文本为准。**

| 拍板项 | 结论 |
|---|---|
| 形态真值来源 | warn_info 原文；`BUSBAR_PLANTYPE` 仅考据存档，**不做表优先路由、不建 command_type 列** |
| 无功增量进不进考核 | **不进**——排除出分母 + 披露计数（政策原文虽提"电压/无功指令"，但 v1_0 算法仅定义电压包络，无功侧合格区间口径未定，纳入无从判起） |
| 冲突处置 | 不适用（既以文本为准，无第二真值即无冲突场景；表值未来如需对照告警另立项） |

排除实现与既有先例完全同构（门控拦截 `gateSkipped` / 脏时间 `dirtyTimeSkipped`：写入前跳过不落库 → 分母天然不含，`PipelineResult` 计数披露）。零 DDL、零迁移、不动权威 rollup SQL 与策略层。

## 2. 改动清单

| 文件 | 改动 |
|---|---|
| [VTargetDecoder.java](../../RuoYi-Vue-springboot3/ruoyi-vqms/src/main/java/com/ruoyi/vqms/statistics/VTargetDecoder.java) | 新增 `isNonVoltage(String)`：文本含「无功增量」→ true；关键词常量 + javadoc 记拍板与 UNVERIFIED。classify/decode 未动 |
| [RegulationPipeline.java](../../RuoYi-Vue-springboot3/ruoyi-vqms/src/main/java/com/ruoyi/vqms/statistics/RegulationPipeline.java) | 脏时间过滤循环内识别跳过（t0 解析后、入 `valid` 前）；`PipelineResult` 加组件 `nonVoltageSkipped`（3 构造点同步）；日志行补「非电压 {}」 |

插入位置选择理由：无功指令不进 `valid` → 不参与 minT0/maxT0 → 曲线预取窗口不为其放宽（读侧成本同防）；脏时间优先于无功（时间坏是更基础失效）。戊·自由组合链路不受影响——无功指令到不了 judge，PolicyAtom/FreeformPolicyEvaluator 无从看到它。
