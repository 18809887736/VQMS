## 一、投运率：扣除电网原因退出时间

- **缘起（政策）**：计算 AVC 装置投运率（= 投运时间 / 并网运行时间 × 100%，合格 ≥99%）时，须**扣除因电网原因造成的 AVC 装置退出时间**（附件6 §一）。
- **需要的判定**：退出原因二分类——**电网原因 / 非电网原因**（免责 vs 计罚）。
- **解决路径**：**AVC 装置（对端 JS 引擎）提供数据**——VQMS 不自判，收结论值。

**现状：✅ 接口已定，待对端实现**
- 对端算好写入 `yc521`（正母）/ `yc522`（副母），三态编码：`0`=未退出 → 计投运分钟；`1`=电网原因（免责）→ 从分母扣除；`2`=非电网原因 → 计入惩罚性退出。
- 点号为建议空号，现场冲突可改，接口契约（取值含义）不变。
- 见 [数据源头（草稿）§四 缺口②](数据源头（草稿）.md)；会议清单 ~~#10~~ 已解决。
- **剩余动作**：① 催对端实现时间表；② 对端确认闭锁信号 → 三态的归类规则。

## 二、免考：全设备顶满仍不达标

- **缘起（政策）**：若发电侧并网主体、新型储能电站已将纳入 AVC 闭环控制的**全部无功设备**，按照其**最大无功功率发出或吸收能力**参与无功电压调节，但仍不满足 AVC 合格标准 → 该时段免于考核（附件6 §三）。
- **需要的判定**：**达到 / 未达到**（全部设备是否已正确方向顶满）。
- **解决路径**：**AVC 装置（对端 JS 引擎）提供数据**——逐设备 Q vs 双向极限 + 方向匹配 + 全设备 AND 的判定义务在对端。

**现状：✅ 2026-08-14 Leo 拍板「判定归对端、应用归 VQMS」**
- VQMS 只收对端给的 `yx501`（全厂一个，二态）：`1`=全设备已正确方向顶满（免考）/ `0`=未顶满（不免考）。
- 统计层**应用**（非判定）：调节不合格 + `yx501=1` → 免考（不计率不计罚，剔除该档分母）；`RegulationJudge` 只出 `{QUALIFIED, PENALIZED}`，`EXEMPT` 不进 judge。
- 见 [数据源头（草稿）§四 缺口③](数据源头（草稿）.md)、[项目规划_v4_0_修订待办.md](项目规划_v4_0_修订待办.md) A2；会议清单 ~~#6~~ 已定。
- **剩余动作**：① 催对端实现 `yx501` 时间表；② 对端确认 SVC/电容等**非发电机无功设备**是否纳入全设备 AND（VQMS 无法自核验）；③ 到位前过渡期免考走人工 / 留空。
