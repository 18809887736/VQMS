## 一、投运率：扣除电网原因退出时间

- **缘起（政策）**：计算 AVC 装置投运率（= 投运时间 / 并网运行时间 × 100%，合格 ≥99%）时，须**扣除因电网原因造成的 AVC 装置退出时间**（附件6 §一）。
- **需要的判定**：退出原因二分类——**电网原因 / 非电网原因**（免责 vs 计罚）。
- **解决路径**：**AVC 装置（对端 JS 引擎）提供数据**——VQMS 不自判，收结论值。

**现状：✅ 接口已定，待对端实现**
- 对端算好写入 `yc521`（正母）/ `yc522`（副母），三态编码：`0`=未退出 → 计投运分钟；`1`=电网原因（免责）→ 从分母扣除；`2`=非电网原因 → 计入惩罚性退出。
- 点号为建议空号，现场冲突可改，接口契约（取值含义）不变。
- 见 [数据源头（草稿）§四 缺口②](数据源头（草稿）.md)；会议清单 ~~#10~~ 已解决。
- **剩余动作**：① 催对端实现时间表；② 对端确认闭锁信号 → 三态的归类规则。

## 二、免考：全设备顶满仍不达标

- **缘起（政策）**：若发电侧并网主体、新型储能电站已将纳入 AVC 闭环控制的**全部无功设备**，按照其**最大无功功率发出或吸收能力**参与无功电压调节，但仍不满足 AVC 合格标准 → 该时段免于考核（附件6 §三）。
- **需要的判定**：**达到 / 未达到**（全部设备是否已正确方向顶满）。
- **解决路径**：**AVC 装置（对端 JS 引擎）提供数据**——逐设备 Q vs 双向极限 + 方向匹配 + 全设备 AND 的判定义务在对端。

**现状：✅ 2026-08-14 Leo 拍板「判定归对端、应用归 VQMS」**
- VQMS 只收对端给的 `yx501`（全厂一个，二态）：`1`=全设备已正确方向顶满（免考）/ `0`=未顶满（不免考）。
- 统计层**应用**（非判定）：调节不合格 + `yx501=1` → 免考（不算不罚；**分母口径 2026-08-19 拍板附件6 原始——不剔分母**，罚款缺额剔免考待确认，见草稿 v5_0 §2.7）；`RegulationJudge` 只出 `{QUALIFIED, PENALIZED}`，`EXEMPT` 不进 judge。
- 见 [数据源头（草稿）§四 缺口③](数据源头（草稿）.md)、[项目规划_v4_0_修订待办.md](项目规划_v4_0_修订待办.md) A2；会议清单 ~~#6~~ 已定。
- **剩余动作**：① 催对端实现 `yx501` 时间表；② 对端确认 SVC/电容等**非发电机无功设备**是否纳入全设备 AND（VQMS 无法自核验）；③ 到位前过渡期免考走人工 / 留空。

## 四、日/月/年统计的预计算（统计表 DDL + Quartz 编排）

- **缘起（架构）**：调节合格率/投运率需要日/月/年汇总。v3.4 曾建分钟级 `voltage_quality_daily/monthly/yearly` + `precompute_cursor`，判定改指令级口径（2026-08-13 拍板）后**整套废弃**——旧部署残留见 `sql/5.0/backup/ry_vqms.sql`。
- **为什么不能查询时算**：判定 CPU 毫秒级不是问题，卡在 I/O——`his_curve_sv` 无索引（每次过滤=对端生产库全表扫）+ 年页单次视图需拉 ~105 万行曲线（~80MB 过网，5~20s），且查询时重算会让历史报表随 `T_fast` 等参数改动变脸，考核数字不可审计。日页勉强可、月临界、年不可行 → 必须预计算冻结结论。
- **解决路径**：**搁置轨 S2~S4，以后再加**（2026-08-20 Leo 确认）。统计 DDL 列被三个未决项吊着（策略丁档标记列 / `T_fast` 默认值 / `invalidTiers`·免考汇总呈现），现在设计=猜。确定轨已预留全部接口面：`vqms_command_ledger` 全量流水（解封后可全历史重算）、`RegulationJudge` 接口、策略参数表、Quartz 脚手架。
- **解封后的懒办法（先记下）**：汇总表 ~800 行/年、全年全量重算秒级——第一版**按日期区间幂等重算（UPSERT）即可，不建增量游标**（`precompute_cursor` 是过度设计教训）；rollup 沿用 v3.1 模式（日→月→年、对计数求和、绝不平均率列），但口径换指令级（分母=发令次数）。

**现状：✅ 已拍板搁置，解封后加**
- 见 [项目规划_v5_0.md](项目规划_v5_0.md) §12.2（S2/S3/S4）。
- **剩余动作**：无前置——随算法定稿同批解封。
