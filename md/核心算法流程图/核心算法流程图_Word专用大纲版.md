# VQMS 核心算法：分钟至日表 Rollup (预计算)

以下是该算法核心流程的**层级大纲版本**，由于 Word 无法直接渲染 Markdown 中的流程图代码，此版本将原本的图形节点结构化地展开，非常适合在 Word 中直接阅读，或者在 Word 中将其直接一键转为 SmartArt 结构图。

## 阶段一：数据获取与格式清洗
1. **输入参数**：统计日期 (`stat_date`) 和母线组编号 (`group_num`)
2. **读取数据 (放宽边界)**：
   - 提取电压原始数据 (`his_curve_sv`) 
   - 提取遥信与状态数据 (`yc_history`)
3. **① 格式校验 (正则匹配)**：
   - **若不匹配**：记日志并标缺。
   - **若匹配**：进入下步 **② 解析为真实时间 (ts)**。
4. **③ 精确范围过滤 (判断 ts 是否属于当天)**：
   - **否 (超出边界)**：丢弃或归入相邻日。
   - **是 (当天数据)**：进入阶段二。

## 阶段二：分桶与时间对齐
1. **按分钟就近取整对齐 (t)**。
2. 建立对应的分桶：
   - **电压桶**：按 `t × busbar_num` 作为 Key，取 `avg_SV` 均值与 `plan_SV` 末条。
   - **状态桶**：按 `t` 作为 Key，取 `yc_time ≤ t` 的最近一条。

## 阶段三：逐分钟遍历判定
对于每个对齐分钟 `t`，执行以下流程：

### 层 0：主母线归属
判断当分钟的主母线编号 (`mainBusbarNum(t)`)：
- **判定失效或无主母线**：整组该分钟空档，不计入任何统计。
- **判定成功**：选取当分钟主母线 (`busbar_num = main`)。

### 层 1：门控关
检查 AVC 投退 / 远方就地 状态：
- **门控命中 (退出或就地)**：剔除该分钟，记入 `excluded_minutes`。
- **门控未命中**：进入层 2。

### 层 2：数据关
检查 `plan_SV` 是否缺值或为废值：
- **是 (缺值/废值)**，进入策略分流 (`plan_sv_invalid_policy`)：
  - 若为 `SKIP`：剔除，记入 `excluded_minutes`。
  - 若为 `COUNT_UNQUALIFIED`：判定为 **不合格**。
  - 若为 `FALLBACK`：回退并进入层 3 判定。
- **否 (数据正常)**：进入层 3。

### 层 3：合格关 (AVC)
计算偏差 `|avg_SV - plan_SV|`，并与容差进行比较：
- **满足容差要求**：**合格**，记入 `qualified`。
- **偏高 (超过正容差)**：**偏高**，记入 `over_high`。
- **偏低 (超过负容差)**：**偏低**，记入 `over_low`。

## 阶段四：日表聚合与持久化
1. **累加当日统计数据**：
   - 汇总并累加合格、偏高、偏低、不合格以及各项剔除的分钟数。
   - 计算 `max_SV`、`min_SV`、`sum(avg_SV)` 等。
2. **更新数据表**：执行 `UPSERT` 操作，将最终结果写入 `voltage_quality_daily` 表。
3. **结束**：完成该组计算。

---

### 附：合格率与对账 (§5.6 / §5.7.1)
- **日**：`qualification_rate = qualified / total × 100`，`total = qualified + over_high + over_low`
- **对账等式**：`total + excluded = 该母线当天充当主母线的全部分钟` (excluded 只含层 1 与 层 2 剔除，**不含**层 0 跳过与组级空档)
- **月/年**：`rate = SUM(qualified) / SUM(total) × 100` (**绝不直接 AVG rate 列**)；`avg_SV` 按 `total` 加权；`excluded = SUM(excluded)`
