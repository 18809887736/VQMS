# 电压合格率口径依据（辽宁省电网）

> 用途：为 VQMS「电压合格率」指标的**口径定义**提供规程依据，关闭 [项目规划_v3_4.md](../md/项目规划_v3_4.md) §4-0 首要待决问题。
> 检索日期：2026-08-10。
> 结论先行：辽宁省没有一份公开、独立、叫《电压合格率细则》的全文文件——电压合格率 / AVC 考核条款**嵌在辽宁电力市场"两个细则"里**（并网运行管理 + 辅助服务管理实施细则）。本文把可查到的框架、对 VQMS 口径判断最关键的几条、以及去哪拿原文列清楚。

## 一、辽宁本省：查"两个细则"

中国省级电网的电压合格率 / AVC 考核，统一收口在各省份电力市场的**"两个细则"**（并网运行管理实施细则 + 辅助服务管理实施细则）里，辽宁也不例外。上位文件是：

**《辽宁省电力市场运营规则》（试行 4.0 版，辽工信电力〔2025〕175 号）** —— 2025-12-13 由省工信厅、省发改委、**东北能源监管局**联合印发。配套实施细则明确：辅助服务市场包括调频，"具备条件时推动**自动电压控制（AVC）**、备用、爬坡、有偿无功调节…以市场化方式开展交易"。

## 二、对 VQMS 口径最关键的三条（外省细则印证，辽宁条款同构）

各省份"两个细则"的 AVC 考核结构高度一致，辽宁条款大概率同构。以下用江苏、山东的公开细则作印证：

### 2.1 AVC 考核拆成两个独立指标（不是笼统的"电压合格率"）
- **AVC 投运率**（装置可用性）
- **AVC 调节合格率**（控制效果） ← **VQMS 算的就是这个**

江苏公开标准（[国家能源局江苏监管办公室文件](https://jsb.nea.gov.cn/dtyw/tz/202512/P020251231517135711511.pdf)）：
- AVC 投运率考核费用上限 **1.5 万元/万千瓦/月**
- AVC 调节合格率考核费用上限 **1 万元/万千瓦/月**

### 2.2 测量方式 = 调度机构 EMS 在线测定，按月分档考核
江苏文件原话：电压合格率由**电力调度机构 EMS 在线测定**。分档示例：
- 月电压合格率 99.5% ≤ x < 100% → 每月考核 2000 元
- 更低档递增

> 这条**强烈支持 v3.4 §4-0 的口径判断**："电压合格率"在火电厂 AVC 场景 = **在线、窄区间、按月考核的 AVC 调节合格率**，不是离线国标 ±10% 审计。

### 2.3 AVC 的标准定义
[山东省电力辅助服务管理实施细则](https://sdb.nea.gov.cn/dtyw/tzgg/202601/P020260106631211820518.pdf) 原话：自动电压控制（AVC）指"在自动装置的控制下，达到最优无功和电压控制的过程，**自动跟踪电力调度指令，实时调整无功出力**"。

> 即"合格"= 跟上 `plan_SV`（调度下发目标）——这正是 v3.4 §5.3 的判定公式 `|average_SV − plan_SV| ≤ tolerance_v`。

## 三、适用辽宁的上位/国标框架（公开可查）

### 3.1 《供电营业规则》（国标兜底合规线）
[司法部公布](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202410/t20241031_508786.html)：用户受电端电压最大允许偏差不超过额定值 **±10%**，110kV 以上受电装置按终端变电站设计。
> 对 220kV 母线即 198~242kV。这是**国标兜底合规线**，与 AVC 窄区间是两套口径，对应 v3.4 §2.1。

### 3.2 《国家电网公司供电电压管理规定》——分级考核
[规定 PDF](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2243/site/attach/0/705c1ba1960c4babb1ee0c39e11d7a6a.pdf) 第四十五条：供电电压实行**分级考核**：
- 国网运检部 → 考核省公司供电电压合格率指标
- 省公司运检部 → 考核地（市）、县公司

> 这决定了 VQMS 统计结果**往上报给谁、谁考核谁**。

### 3.3 国家能源局《关于进一步加强电压合格率数据统计分析工作的通知》（2023）
[国家能源局通知](http://zfxxgk.nea.gov.cn/2023-08/18/c_1310740549.htm)：
- 各电网企业**每季度首月 10 日前**报送上一季度电压合格率数据
- 7 月 20 日 / 次年 1 月 20 日前报半年 / 全年分析报告
- 通过 [pqm.nea.gov.cn](https://pqm.nea.gov.cn) 系统上报
- 中央电网企业**逐级汇总**

## 四、对 VQMS 的落地结论

| v3.4 待决/辨析 | 规程依据 | 状态 |
|---|---|---|
| **"电压合格率"口径 = AVC 调节合格率**（非国标 ±10%） | 辽宁"两个细则"AVC 条款 + 江苏细则"EMS 在线测定、按月分档考核" | ✅ 印证，待现场条款最终确认 |
| 阈值公式 `\|average_SV − plan_SV\| ≤ tolerance_v` | AVC 定义"自动跟踪调度指令"（山东细则） | ✅ 印证 |
| ±10% 是另一套口径（合规兜底，非 AVC 考核线） | 《供电营业规则》 | ✅ 印证（v3.4 §2.1） |
| 统计结果上报路径 | 国网分级考核 + NEA 季度/年度报送 | ✅ 明确 |
| `tolerance_v` 初值（220kV=300V / 500kV=500V） | 待辽宁"两个细则"AVC 条款原文核实 | ⏳ 待现场 |

## 五、下一步行动

请现场提供 [辽宁"两个细则"配套实施细则](https://gxt.ln.gov.cn/gxt/tztg/2024110615382731258/2024110616072490170.pdf)（本地存档 `政策口径/2024110616072490170.pdf`）中 **AVC 投运率 / 调节合格率的具体条款**：
1. 月电压合格率分档阈值（如 99.5% / 99% / 98%…）
2. 各档考核费用
3. **容差数值**（即 `plan_SV ± ?V`，对应 `tolerance_v`）

拿到后：v3.4 §4-0"首要待决问题"即可关闭；`tolerance_v` 初值可从条款直接读出，填进 `busbar_threshold` 表（§5.2）。
